Вопросы
Что такое токен? +
Токен — часть слова. ~1000 токенов ≈ 750 слов на английском или ~500 слов на русском.
Почему выход дороже? +
Модели генерируют ответ по одному токену, каждый требует вычислений. Промпт обрабатывается параллельно, поэтому дешевле в 3–5 раз.
Цены актуальны? +
Да, данные обновляются автоматически каждый день с публичной базы LiteLLM.
Как сэкономить? +
Используй кэширование промптов (в 10–30× дешевле), Batch API (скидка 50%), и выбирай mini/flash версии для простых задач.
