#  AI Cost Calculator

**Калькулятор стоимости запросов к нейросетям. Цены обновляются автоматически.**

![AI Cost Calculator](https://xec11psex.github.io/ai-cost-calculator/)

## 📖 О проекте

AI Cost Calculator — это веб-приложение для точного расчёта стоимости запросов к популярным AI-моделям: GPT-4.1, GPT-4o mini, Claude Sonnet 5, Claude Opus 5, Gemini 2.5 Pro и DeepSeek V4.

Цены на API обновляются **автоматически каждый день** через GitHub Actions, поэтому вы всегда видите актуальные данные.

## ✨ Возможности

- 🧮 **Расчёт стоимости** — узнайте точную цену вашего запроса в долларах и рублях
- 🔄 **Реверс** — рассчитайте, сколько запросов можно сделать на определённый бюджет
- 📊 **Сравнение** — сравните стоимость разных моделей между собой
- 📈 **Анализ** — оцените месячные и годовые расходы на использование AI
- 🌍 **Двуязычность** — интерфейс на русском и английском языках
- 💰 **Автоматическое обновление цен** — данные актуальны всегда
